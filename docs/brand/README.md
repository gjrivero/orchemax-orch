# Brand assets (OrcheMax)

Shared mark for this packs repo and GitHub social. Product site embeds live in **orchemax** (`server/web/static/brand/`).

**Isotipo-first:** Markdown cannot set a custom font, so every header in this repo is the isotipo image followed by a plain `# OrcheMax` text heading — never the old horizontal wordmark. There is no horizontal `logo-*.png` in this repo for that reason; if a future asset needs one (a slide deck, a doc site theme), regenerate it from the Canva source below rather than reusing a stale export.

| File | Use |
|------|-----|
| `isotipo-*.png` | Mark / avatar / README + docs header |
| `og-card.png` | Social preview source |
| `favicon.ico` | Optional docs sites |
| `apple-touch-icon.png` | Optional docs sites |

Source: Canva **Isotipo + logo Orchemax** (`DAHVKzMLzOs`). Do not invent alternate marks in language packs.
